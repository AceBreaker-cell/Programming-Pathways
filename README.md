### 📖 Tentang Game

**Programming Pathways** adalah game **2D Platformer** yang memadukan aksi lompat-lompatan klasik dengan tantangan trivia! Jelajahi dunia pixel art, temukan **10 patung misterius** yang tersebar di sepanjang map, dan jawab pertanyaan mereka untuk mengumpulkan skor setinggi mungkin tapi hati-hati, sekali kamu terjatuh ke air, permainan berakhir.

### ✨ Fitur

| Fitur | Deskripsi |
|---|---|
| 🗿 **10 Pos Patung** | Setiap patung menyimpan 5 pertanyaan acak, berbeda setiap kali main |
| 💬 **Popup Animasi** | Kertas pertanyaan slide-up dengan overlay gelap di belakangnya |
| 🎯 **Sistem Skor** | Poin dari jawaban benar, lengkap dengan tracking Pos (X/10) |
| 🏆 **High Score** | Skor terbaik tersimpan otomatis di perangkat |
| ⭐ **Rating Akhir** | Dari E sampai A+, warna menyesuaikan performa (hijau/kuning/merah) |
| ⏸️ **Menu Pause** | Lengkap dengan slider volume untuk musik & sound effect |
| 💀 **Sistem Kematian** | Jatuh ke air memicu transisi fade dramatis sebelum layar retry |
| 🌊 **Air Bergerak** | Efek gelombang animasi pada air |
| 🏔️ **Parallax Background** | Latar belakang looping tak terbatas |
| 🎵 **Musik & SFX Dinamis** | Musik berbeda untuk menu & gameplay + SFX lompat, klik, jawaban, kematian, kemenangan |
| ✨ **Particle Effect** | Efek visual setiap kali menjawab pertanyaan |

### 🎮 Cara Bermain

1. **Panah Kiri/Kanan** = bergerak
2. **Panah Atas** = melompat
3. Dekati patung sampai muncul **panah hijau** di atasnya
4. Tekan **E** untuk membuka pertanyaan
5. Pilih salah satu dari 2 jawaban
6. Selesaikan semua 10 patung untuk melihat rating akhir kamu!

- **Unity 6** = game engine

### 📦 Cara Build Sendiri

```bash
git clone https://github.com/AceBreaker-cell/Programming-Pathways.git
```

1. Buka folder project menggunakan **Unity Hub** (Unity 6.4 ke atas)
2. Buka scene `MainMenu` di `Assets/Scenes`
3. Klik Play untuk coba di Editor, atau **File → Build Settings** untuk build ke platform pilihanmu
