### 📖 About

**Programming Pathways** is a **2D Platformer** that blends classic jump-and-run action with trivia challenges! Explore a pixel-art world, find **10 mysterious statues** scattered across the map, and answer their questions to rack up the highest score possible but be careful, falling into the water means game over.

### ✨ Features

| Feature | Description |
|---|---|
| 🗿 **10 Statue Checkpoints** | Each statue holds 5 randomized questions, different every playthrough |
| 💬 **Animated Popups** | The question paper slides up with a darkened background overlay |
| 🎯 **Scoring System** | Earn points for correct answers, with live Pos (X/10) tracking |
| 🏆 **High Score** | Best score is automatically saved on your device |
| ⭐ **End-Game Rating** | From E to A+, color-coded by performance (green/yellow/red) |
| ⏸️ **Pause Menu** | Includes a volume slider for music & sound effects |
| 💀 **Death System** | Falling into water triggers a dramatic fade transition before the retry screen |
| 🌊 **Animated Water** | Smooth wave motion for a lively environment |
| 🏔️ **Parallax Background** | Seamless infinite-looping background |
| 🎵 **Dynamic Music & SFX** | Separate music for menu & gameplay + SFX for jump, click, answers, death, victory |
| ✨ **Particle Effects** | Visual feedback every time you answer a question |

### 🎮 How to Play

1. **Left/Right Arrow** = move
2. **Up Arrow** = jump
3. Approach a statue until a **green arrow** appears above it
4. Press **E** to open the question
5. Choose one of 2 answers
6. Complete all 10 statues to see your final rating!

### 📦 Build It Yourself

```bash
git clone https://github.com/AceBreaker-cell/Programming-Pathways.git
```

1. Open the project folder with **Unity Hub** (Unity 6.4 or newer)
2. Open the `MainMenu` scene inside `Assets/Scenes`
3. Hit Play to test in the Editor, or use **File → Build Settings** to build for your target platform
